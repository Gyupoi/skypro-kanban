# Kanban

Приложение для управления задачами в формате Kanban-доски.

## Возможности

* Регистрация и авторизация
* Создание задач
* Редактирование задач
* Удаление задач
* Просмотр задач
* Получение задач с API
* Распределение задач по статусам
* Skeleton Loader при загрузке

## Технологии

* React
* React Router
* JavaScript
* styled-components
* Context API
* Fetch API

## Запуск проекта

```bash
npm install
npm run dev
```

## API

Для работы приложения используется API SkyPro.

## Статусы задач

* Без статуса
* Нужно сделать
* В работе
* Тестирование
* Готово
